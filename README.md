# D-Gantt demo

The built demo pages of D-Gantt. This repository holds only the compiled site, not the source.

| Page | Shows |
|---|---|
| [Gantt](https://ranjanfbt.github.io/d-gantt-demo/) | 20k-task chart: zoom, themes, editing |
| [React](https://ranjanfbt.github.io/d-gantt-demo/react.html) | The same chart through the React wrapper |
| [Site](https://ranjanfbt.github.io/d-gantt-demo/site.html) | Gantt, 3D BIM and drawings on one selection |
| [Project controls](https://ranjanfbt.github.io/d-gantt-demo/controls.html) | P6 scheduling, resources, cost, and the site registers |
| [Project setup](https://ranjanfbt.github.io/d-gantt-demo/setup.html) | Floor plan → locations → BIM → recommended schedule |

All project data is sample data, and anything you enter stays in your browser.

DXF floor plans work here. DWG needs a converter service, because this site is static: without one, the setup page asks you to upload a DXF.
